# Data dictionary

Full column-level docs + lineage are generated by dbt:

```bash
dbt docs generate --profiles-dir profiles && dbt docs serve
```

This is the model reference. Raw source columns are documented in
[`../data_generator/README.md`](../data_generator/README.md) (with the defect ledger).

## Marts (what each table is)

| Model | Grain | Purpose |
|---|---|---|
| `dim_date` | day | Date spine for cohorts/freshness |
| `dim_accounts` | account | Conformed account dim (canonical segment) |
| `dim_users` | rep | Conformed rep dim (role, segment, timezone) |
| `fct_leads` | lead | Furthest stage reached, canonical MQL timing, speed-to-lead, SLA |
| `fct_mqls` | MQL event | Canonical MQLs (score ≥ 50), cohorted by MQL month |
| `fct_opportunities` | opportunity | Canonical opp fact; `is_net_new_pipeline` flag for KPI #5 |
| `fct_opportunity_stage` | opp × stage spell | Time-in-stage, enriched with segment |
| `fct_funnel_conversion` | segment × stage | Leads reaching each stage + step conversion |
| `fct_stage_velocity` | segment × stage | Median / avg / p90 days-in-stage |
| `fct_cohort_progression` | cohort × months_since × segment | MQL cohort progression triangle |
| `fct_metric_values` | metric × grain × period × segment | The single source for every KPI number |
| `dim_metric_catalog` | metric | Governed catalog projection + golden values |
| `rpt_metric_reconciliation` | metric × variant | "Which number is right?" — each team's number vs canonical |
| `rpt_source_freshness` | source | Recency vs SLA (anchored) |

## Key conventions

- **lead grain** = `hs_contact_id` (stable); `sf_lead_id` is a nullable attribute from the
  crosswalk, so the ~8% unmatched leads are kept, not dropped.
- **Canonical MQL** = lead score ≥ 50 (HubSpot's ≥ 40 is the documented drift).
- **Net-new pipeline** (`is_net_new_pipeline`) = New Business, not partner-sourced,
  positive USD amount, Stage ≥ 1 — encodes KPI Dictionary #5.
